# Accessibility

I want the results in this repository to be readable by anyone, including people using screen readers, high-contrast or dark themes, or small screens.

## What I Do

- **Figures** (`assets/*.svg`) are generated by scripts, carry a text title and a description that states the main result, and adapt to light and dark themes. Every number in a figure is also in a table in the linked document.
- **Colors** come from one palette (blue, orange, gray) chosen to stay distinguishable for common forms of color blindness. Each marker also carries a hover title with its value, and the legend names every color.
- **Documents** are Markdown with headings and tables, readable on GitHub and with standard tools.

## Known Limitations

- The `.docx` and `.pdf` papers are generated automatically and have not been checked with a screen reader.
- Some tables in the checkpoints are wide and need horizontal scrolling on small screens.
- Data files (`.jsonl`, `.csv`) are machine-readable but large.

## Report a Barrier

If something here is hard to read or use, open an issue with the "Question about a result" template and describe the barrier, or contact me through my GitHub profile ([@awabmoha](https://github.com/awabmoha)).
