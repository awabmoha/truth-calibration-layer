## ACL Format

The Phase 2 paper uses the official ACL LaTeX style ([acl-org/acl-style-files](https://github.com/acl-org/acl-style-files)). The style files are not copied into this repository. To build a PDF, open the ACL template on Overleaf, replace its `.tex` with the paper's `.tex`, upload the `references.bib`, and compile. Locally, put `acl.sty` and `acl_natbib.bst` from the official repository next to the `.tex` and run `tectonic -X compile tcl-phase2-negative-result.tex` (how the committed PDF was built), or `pdflatex`, `bibtex`, then `pdflatex` twice.

## TMLR Format

The final paper uses the official TMLR style ([JmlrOrg/tmlr-style-file](https://github.com/JmlrOrg/tmlr-style-file)), also not copied into this repository. Put `tmlr.sty`, `tmlr.bst`, and `fancyhdr.sty` next to `tcl-final.tex`, then run `tectonic -X compile tcl-final.tex` for the named preprint and `tectonic -X compile tcl-final-anon.tex` for the anonymous submission (Tectonic 0.17.0 built both committed PDFs). The anonymous file only defines `\ANON`, which switches the style to review mode and removes the repository links and the self-citation. To regenerate the figures from the recorded results: `python paper/tcl-final/make_figures.py`.
